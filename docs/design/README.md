# Interface reference

The accepted implementation references are `workspace-desktop.png` (1536×1024) and `workspace-mobile-settings.png` (390×844 mobile plus desktop settings state).

## Design system

- Canvas: `#f6f7f9`; surface: `#ffffff`; text: `#171a1f`; border: `#d8dde6`.
- Primary accent: `#2a5db0`; success: `#19724b`; warning: `#9a5b13`; failure: `#b42318`.
- UI uses the system sans-serif stack; source uses the system monospace stack.
- Borders are 1 px, corners are 4 px, and shadow is reserved for the settings drawer.
- The cobalt syntax spine links editor panes, status, and diagnostics as the signature visual element.
- App UI is open bands and rails rather than nested cards. There are no gradients, glass surfaces, or decorative illustrations.
